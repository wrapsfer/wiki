# Wrapsfer API Documentation

Reference for the **current** behavior of the Wrapsfer API, written for API
consumers, backend developers, and future maintainers.

## What Wrapsfer Is

Wrapsfer is a **tenant-aware logistics and warehouse API** built on .NET 10. It
manages a partner's catalogue of products, waybills used to pack and hand off
shipments, and the supporting concerns around them — stock tracking, low-stock
alerting, CSV/XLSX import and export, audit logging, and email notifications.

Every authenticated request is bound to a tenant (a Keycloak realm). Owner-realm
users may act on behalf of a partner tenant by passing a `tenantId` query
parameter. Repository queries and mutations are scoped to that tenant.

This documentation describes only what is implemented in the codebase today.

## At A Glance

- **Versioned routes.** All resource endpoints live under `/api/v1/...` and
  are decorated with `[Authorize]` through `ApiControllerBase`.
- **Authentication.** Keycloak JWT bearer tokens, with per-realm OIDC
  discovery via a multi-tenant `JwtBearerEvents` handler.
- **Tenant resolution.** Realm derived from the `X-Tenant-Realm` header or
  the request subdomain, with an owner-realm override path for partner
  operations.
- **Persistence.** PostgreSQL via EF Core, with `AuditableEntity`,
  `DomainEvent`, and `AuditLog` interceptors hooked into `SaveChanges`.
- **Messaging.** RabbitMQ-backed export consumers and a mail-processing
  consumer; a background job auto-cancels stale draft waybills hourly.
- **Mailing.** Resend via FluentEmail, with Fluid templates rendered from
  files for low-stock alerts, stock recovery, and product exports.

## Modules

| Module               | Route                              | Purpose                                                |
| -------------------- | ---------------------------------- | ------------------------------------------------------ |
| Me                   | `GET /api/v1/me`                   | Current user, tenant, and roles.                       |
| Products             | `/api/v1/products`                 | Catalogue: Single, Bundle, Package products.           |
| Waybills             | `/api/v1/waybills`                 | Pack/handoff lifecycle with stock reservation.         |
| Tenant Settings      | `/api/v1/tenant-settings`          | Default low-stock threshold and email recipients.      |
| Stock Alerts         | `/api/v1/stock-alerts`             | Read-only history of low-stock and recovery events.    |
| Health               | `GET /health`                      | DB and RabbitMQ liveness aggregate.                    |
| OpenAPI              | `GET /openapi/v1.json`             | OpenAPI document, **Development only**.                |
