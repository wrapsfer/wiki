# API Overview

A high-level view of the Wrapsfer API as implemented today: a tenant-aware
.NET 10 Web API for catalogue, waybill, stock, and notification management.

## Purpose

Wrapsfer exposes the operational surface of a logistics/warehouse partner:

- A catalogue of **Products** (Single, Bundle, Package).
- **Waybills** that move from Draft → Packed → HandedOff (or Cancelled),
  with stock reserved on item add and consumed on hand-off.
- **Tenant Settings** for the default low-stock threshold and notification
  recipients.
- **Stock Alert** history for low-stock and recovery events.
- **Imports/exports** via CSV and XLSX, with exports delivered asynchronously
  by email.

Every endpoint that returns or mutates business data is scoped to the
authenticated tenant.

## Stack

- **.NET 10** Web API.
- **ASP.NET Core controllers** with [API Versioning](https://github.com/dotnet/aspnet-api-versioning)
  via URL segments (`api/v{version:apiVersion}/...`). Default version `1.0`.
- **MediatR** for CQRS commands and queries.
- **FluentValidation** with a `ValidationBehavior<TRequest, TResponse>`
  pipeline that validates requests before they reach handlers.
- **EF Core 10 + PostgreSQL** (Npgsql provider). `AuditableEntityInterceptor`,
  `DomainEventInterceptor`, and `AuditLogInterceptor` are registered on the
  `DbContext`.
- **Keycloak JWT** authentication, with per-realm OIDC discovery and a
  realm resolver driven by `X-Tenant-Realm` header / request subdomain.
- **RabbitMQ** for async export workflows (`products.export`, `waybills.export`,
  `wrapsfer.mail`) consumed by hosted services.
- **Resend** for transactional email through FluentEmail; templates rendered
  with [Fluid](https://github.com/sebastienros/fluid).
- **Serilog** logging, configured from `appsettings.json`.
- **Health checks** exposed at `/health`, aggregating the PostgreSQL and
  RabbitMQ checks registered at startup.
- **OpenAPI** via `Microsoft.AspNetCore.OpenApi`, mapped only when
  `app.Environment.IsDevelopment()`.
- **JSON enums** are serialized as strings (`JsonStringEnumConverter` is
  globally registered).

## Solution Layout

```text
src/
  Wrapsfer.Api/             ASP.NET Core host, controllers, contracts, filters, exception handling
  Wrapsfer.Application/     MediatR commands/queries, validators, behaviors, services
  Wrapsfer.Domain/          Aggregates, domain events, repository interfaces, Result<T>/Error
  Wrapsfer.Infrastructure/  EF Core, repositories, interceptors, Keycloak auth, RabbitMQ, jobs
  Wrapsfer.Mailing/         Resend integration, Fluid templates, mail queue + consumer
tests/
  Wrapsfer.Application.Tests/
  Wrapsfer.Domain.Tests/
  Wrapsfer.IntegrationTests/
  Wrapsfer.Mailing.Tests/
```

Dependency direction: `Api` → (`Application`, `Infrastructure`, `Mailing`),
`Infrastructure` → (`Application`, `Domain`), `Application` → `Domain`,
`Mailing` is independent of `Domain`/`Application`.

## Endpoint Summary

All resource controllers inherit from `ApiControllerBase`, which carries
`[ApiController]`, `[Authorize]`, `[ApiVersion("1.0")]`, and the route
prefix `api/v{version:apiVersion}/[controller]`. Modules under `/api/v1/...`
are also wrapped by `TenantResolutionFilter` (which enforces the owner-realm
`tenantId` query parameter requirement).

| Module           | Endpoint                                                              | Notes                                              |
| ---------------- | --------------------------------------------------------------------- | -------------------------------------------------- |
| Me               | `GET /api/v1/me`                                                      | Returns `{userId, tenantId, roles}`.               |
| Products         | `POST /api/v1/products`                                               | Create a product.                                  |
|                  | `GET /api/v1/products`                                                | List with `search`, `type`, `page`, `pageSize`.    |
|                  | `GET /api/v1/products/{id}`                                           | Get by ID.                                         |
|                  | `GET /api/v1/products/by-barcode/{barcode}`                           | Get by tenant-scoped barcode.                      |
|                  | `GET /api/v1/products/by-sku/{skuCode}`                               | Get by SKU code.                                   |
|                  | `PUT /api/v1/products/{id}`                                           | Update (partial; supports clear flags).            |
|                  | `DELETE /api/v1/products/{id}`                                        | Delete.                                            |
|                  | `PATCH /api/v1/products/{id}/stock`                                   | Set absolute stock quantity.                       |
|                  | `POST /api/v1/products/{id}/unpack`                                   | Unpack a Package into its target product.          |
|                  | `POST /api/v1/products/import`                                        | CSV/XLSX upload, max 20 MB.                        |

|                  | `GET /api/v1/waybills/number-available?waybillNumber=...`             | Tenant-scoped number availability.                 |

|                  | `PUT /api/v1/waybills/{id}/items/{itemId}`                            | Update item quantity.                              |

## Cross-Cutting Behaviors

- **Result → HTTP mapping.** `ApiControllerBase.ToActionResult` /
  `ToCreatedResult` map domain `Result<T>` outcomes:
  `ErrorType.NotFound` → `404`, `Validation` → `400`, `Conflict` → `409`,
  any other failure → `400`.
- **ProblemDetails everywhere.** The global exception handler in
  `Wrapsfer.Api.Extensions.WebApplicationExtensions.ConfigurePipeline` returns
  `application/problem+json` and adds a `traceId` extension. Database errors
  map to `503`, configuration errors to `503`, timeouts to `504`,
  unexpected to `500`.
- **Validation extensions.** Model-state validation failures emit a
  `ProblemDetails` with an `errors` extension (field → messages) and a
  `traceId`.
- **Audit logging.** Every non-`AuditLog` insert/update/delete is recorded
  in `audit_logs` by `AuditLogInterceptor`, redacting properties marked
  `[SensitiveData]`.
- **Domain events.** Aggregates raise events (e.g. `LowStockDetectedEvent`)
  and `DomainEventInterceptor` publishes them via MediatR after `SaveChanges`.
